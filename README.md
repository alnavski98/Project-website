# Project Website

A side project I made to personally display various projects I'm working on for fun

## Features

- Tabs to browse between basic information and project page
- Flask implementation

## Getting Started

### Prerequisites

Ensure that you at least have python 3.11 installed

### Installation

1. Clone the repository with `git clone https://github.com/alnavski98/Project-website.git`
2. Create the virtual environment with `python -m venv .venv`
3. Activate the virtual environment with `.\.venv\Scripts\Activate.ps1`
4. Install flask with `pip install flask`
5. Install the required libraries with `pip install -r requirements.txt`

### Running

To run the application, ensure you are in the root folder and type `python -m flask --app app run --debug`
